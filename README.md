A deterministic 4 KB Python chess engine for make.fun tiny-chess-01. It searches a fixed node budget with principal variation search, a transposition table, killer moves, and quiescence.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
